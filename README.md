# jRadio

Настольный аудиоплеер: интернет-радио, музыка с USB-флешки, SD-карты и
медиасервера в домашней сети, Яндекс Музыка. Управление ручкой и четырьмя
кнопками на самом устройстве или из браузера с телефона и компьютера.

*[English version](README.en.md)*

---

## Характеристики

| | |
|---|---|
| Процессор | ESP32-S3 QFN56, 16 МБ flash, 8 МБ PSRAM |
| Экран | по SPI: ILI9341 или ST7789 320×240, ILI9488 или ST7796S 480×320 — каждый в двух ориентациях; ST7789 320×170 (модуль 1,9") — только горизонтально |
| Звук | ЦАП PCM5102 по I2S, линейный выход; 16 бит, стерео; необязательный вывод MUTE усилителя |
| Носители | USB Host для флешки и слот microSD, FAT16 или FAT32 |
| Сеть | Wi-Fi 2,4 ГГц, до пяти сохранённых сетей, веб-интерфейс в локальной сети |
| Управление | поворотный энкодер с кнопкой и четыре кнопки |
| Прошивка | ESP-IDF 5.5.x, цель `esp32s3` |

Какие детали стоят и как они разведены — одной строкой в
[`board_options.h`](board_options.h); он же решает, что окажется на главном
экране. Подробности — [«Оборудование»](doc/hardware.md).

## Что умеет

| Функция | Состояние | Подробнее |
|---|---|---|
| **Интернет-радио** | работает | Свой список станций, название трека прямо из эфира, переподключение при обрыве |
| **Музыка с USB-флешки** | работает | Проход по папкам, теги, обложки, перемотка, автопереход к следующему треку |
| **Музыка с SD-карты** | работает | То же самое; карта опознаётся при входе в источник |
| **Плейлисты на носителе** | работает | Файлы `.m3u`, `.m3u8` и `.pls` открываются как папка — [подробнее](doc/usage.md#плейлисты-на-носителе) |
| **Яндекс Музыка** | работает | «Моя волна» и станции аккаунта, обложка, «нравится» и «не нравится» — [подробнее](doc/yandex.md) |
| **Медиасервер (DLNA)** | работает | Сам находит сервер в сети, проход по дереву, теги и обложка — [подробнее](doc/dlna.md) |
| **Веб-интерфейс** | работает | Плеер, настройки, редактор списка станций, просмотр файлов, Wi-Fi — [подробнее](doc/web.md) |
| **Часы** | работает | Время из интернета, на всех экранах |
| **Погода** | работает | Температура и значок рядом с часами; Open-Meteo, wttr.in или OpenWeatherMap на выбор, координаты в веб-настройках — [подробнее](doc/usage.md#погода) |
| **Заставка** | работает | Затемнение, чёрный экран или плывущие по нему часы с датой, погодой и названием трека; через 15 с — 10 мин без прикосновений — [подробнее](doc/usage.md#настройки) |
| **Громкость** | работает | Ручкой, в вебе и в настройках; запоминается |
| **Автозапуск** | работает | Само включает то, что играло до выключения: станцию, трек с носителя, станцию ЯМузыки или папку медиасервера; для Bluetooth возвращает экран ожидания телефона |
| **Глубокий сон** | работает | Удержание первой кнопки гасит устройство: воспроизведение останавливается, Bluetooth и Wi-Fi уходят корректно, а с отдельным ключом питания обесточивается и вся внешняя обвязка. Будит та же кнопка — [подробнее](doc/usage.md#глубокий-сон) |
| **Быстрые настройки** | работает | Кнопка F2 опускает окно поверх экрана: таймер сна, будильник, яркость и колонка BT — ручкой, не уходя с плеера — [подробнее](doc/usage.md#быстрые-настройки) |
| **Таймер сна** | работает | Играть 15–120 минут, затем плавно убрать громкость и уснуть; ставится в веб-настройках, обратный отсчёт виден на экране и в плеере — [подробнее](doc/usage.md#таймер-сна) |
| **Пульт** | работает | Любой инфракрасный пульт через приёмник на одной ноге: кнопки обучаются на странице веб-интерфейса, цифры набирают станцию по номеру, а обученная кнопка «Сон» будит устройство из глубокого сна с первого нажатия — [подробнее](doc/usage.md#пульт) |
| **Будильник** | работает | Станция в заданное время, по выбранным дням недели и со своей громкостью. Спящее устройство просыпается само: сперва тихо, за десять минут, чтобы сверить часы, потом за минуту до звонка — [подробнее](doc/usage.md#будильник) |
| **Обложки** | работает | Из тега файла, из `cover.jpg` рядом с музыкой, от Яндекса |
| **Язык интерфейса** | работает | Русский и английский; переключатель меняет и экран устройства, и веб-интерфейс |
| **Категории ЯМузыки** | не сделано | Показываются только станции аккаунта; общего каталога жанров и настроений нет |
| **Bluetooth** | работает | Через модуль [jradio-bt](https://github.com/jmper-ha/jradio-bt) на том же I2S, в обе стороны: приём с телефона (трек, обложка, кнопки, громкость) и звук на Bluetooth-колонку с её кнопками — [подробнее](doc/usage.md#bluetooth). Без модуля пункта в меню нет |
| **FM** | не сделано | Пункта в меню нет: устройство показывает только то, что умеет |

### Форматы

| Формат | Радио | Файлы | Замечания |
|---|:---:|:---:|---|
| MP3 | да | `.mp3` | |
| AAC | да | `.aac`, `.adts` | Только «сырой» ADTS. `.m4a` — это AAC в контейнере MP4, он не читается |
| FLAC | да | `.flac` | Играет и в 24 бита |
| Ogg | да | `.ogg`, `.oga` | Внутри может быть FLAC, Vorbis или Opus — что именно, читается из потока |
| WAV | — | `.wav` | 16 бит, моно или стерео |
| HLS (`.m3u8`) | да | — | Сегменты в MP3 или AAC. Поток в MPEG-TS не разбирается |

Радио работает и по HTTP, и по HTTPS. Перемотка есть только у файлов: ни у
радио, ни у станции ЯМузыки нет ни длины, ни позиции. Подробности и оговорки —
[«Форматы: подробности»](doc/usage.md#форматы-подробности).

## Текущий статус

Устройство собрано и работает каждый день; всё, что помечено выше как
«работает», проверено на живой плате, а не только в тестах.

Известные ограничения, о которых стоит знать заранее:

- **Веб-интерфейс рассчитан только на доверенную локальную сеть.**
  Аутентификации нет, `Origin` не проверяется. Наружу не открывать.
- **Не более 99 станций** в плейлисте и **256 записей** в одном каталоге
  носителя; лишнее отбрасывается с предупреждением.
- **exFAT не поддерживается** — накопители от 64 ГБ обычно приходят с завода
  именно в нём и требуют переформатирования.

Полный список ограничений с числами — в
[«Диагностика и ограничения»](doc/diagnostics.md).
