# jRadio

Аудиоплеер на ESP32-S3: интернет-радио, музыка с USB-флешки и
SD-карты, медиасервер домашней сети, Яндекс Музыка и Bluetooth. Управляется
энкодером и кнопками на корпусе, инфракрасным пультом или из браузера — с
телефона и компьютера в той же сети.

*[English version](README.en.md)*

---

## Особенности

- **Всё в одном.** Радио, файлы, DLNA, Яндекс Музыка, Bluetooth в обе стороны —
  один плеер вместо нескольких устройств.
- **Собирается из доступных деталей.** Модуль ESP32-S3, дисплей по SPI, ЦАП
  PCM5102, энкодер и кнопки. Никаких заказных плат — макетка или простая
  печатная плата.
- **Настраивается под вашу плату одной строкой на деталь.** Дисплей, ЦАП,
  распиновка, что стоит и чего нет — в [`board_options.h`](board_options.h).
  Чего нет на плате, того нет и в меню.
- **Веб-интерфейс из коробки.** Плеер, редактор списка станций с картинками,
  настройки, файлы, обучение пульта — всё с телефона, без приложений.
- **Работает каждый день.** Автозапуск того, что играло, глубокий сон,
  будильник, таймер сна, часы и погода на экране, заставка.
- **Открытый код и понятная сборка.** ESP-IDF, VS Code, одна кнопка сборки.
  Готовые файлы прошивки — в [релизах](https://github.com/jmper-ha/jradio/releases).

## Из чего состоит

| | |
|---|---|
| Процессор | модуль ESP32-S3, 16 МБ flash, 8 МБ PSRAM |
| Экран | по SPI: ILI9341 или ST7789 320×240, ILI9488 или ST7796S 480×320 — горизонтально или вертикально; ST7789 320×170 (модуль 1,9") |
| Звук | ЦАП PCM5102 по I2S, линейный выход, 16 бит стерео; по желанию — управление MUTE усилителя |
| Носители | USB-флешка (USB Host) и microSD; FAT16/FAT32 |
| Сеть | Wi-Fi 2,4 ГГц, до пяти сохранённых сетей |
| Управление | энкодер с кнопкой, четыре кнопки, ИК-пульт (любой, обучается) |
| Bluetooth | через модуль [jradio-bt](https://github.com/jmper-ha/jradio-bt) на втором ESP32 |
| Прошивка | ESP-IDF 5.5.x, цель `esp32s3` |

Подробная распиновка и выбор деталей — в [«Оборудовании»](doc/hardware.md).

## Что умеет

| | |
|---|---|
| **Интернет-радио** | Свой список станций (до 99), название трека из эфира, HTTP и HTTPS, переподключение при обрыве |
| **Музыка с USB и SD** | Папки, теги (включая русские в старых кодировках), обложки, перемотка, автопереход к следующему треку. Плейлисты `.m3u`, `.m3u8`, `.pls` открываются как папки, альбомы с `.cue` — по трекам |
| **Яндекс Музыка** | «Моя волна» и станции аккаунта, обложки, «нравится» / «не нравится» — [подробнее](doc/yandex.md) |
| **Медиасервер (DLNA)** | Сам находит сервер в сети, обход библиотеки, теги и обложки — [подробнее](doc/dlna.md) |
| **Bluetooth** | Приём с телефона (трек, обложка, кнопки, громкость) и вывод на Bluetooth-колонку или наушники — [подробнее](doc/usage.md#bluetooth) |
| **Веб-интерфейс** | Плеер, настройки, редактор станций, файлы, Wi-Fi, пульт, резервная копия — [подробнее](doc/web.md) |
| **Пульт** | Любой ИК-пульт: кнопки обучаются в браузере, цифры набирают номер станции, обученная кнопка будит устройство из сна — [подробнее](doc/usage.md#пульт) |
| **Часы и погода** | Время из интернета, температура и значок неба рядом с часами (Open-Meteo, wttr.in или OpenWeatherMap) |
| **Заставка** | Затемнение, чёрный экран или плывущие часы с датой, погодой и названием трека |
| **Быстрые настройки** | Окно поверх плеера: таймер сна, будильник, яркость, колонка BT — не уходя с экрана |
| **Будильник** | Станция в заданное время по дням недели со своей громкостью; спящее устройство просыпается само |
| **Таймер сна** | 15–120 минут, затем плавное затухание и сон |
| **Глубокий сон** | Удержание кнопки гасит устройство; будит та же кнопка или пульт. С ключом питания обесточивается вся обвязка |
| **Автозапуск** | После включения продолжает то, что играло: станцию, трек, папку сервера |
| **Два языка** | Русский и английский — и на экране, и в браузере, переключаются на лету |

Чего пока нет: FM-радио и общего каталога жанров Яндекс Музыки (только станции
аккаунта).

### Форматы

| Формат | Радио | Файлы | Замечания |
|---|:---:|:---:|---|
| MP3 | да | `.mp3` | |
| AAC | да | `.aac`, `.adts` | Только ADTS; `.m4a` (MP4-контейнер) не читается |
| FLAC | да | `.flac` | В том числе 24 бита |
| Ogg | да | `.ogg`, `.oga` | FLAC, Vorbis или Opus внутри |
| WAV | — | `.wav` | 16 бит, моно или стерео |
| HLS (`.m3u8`) | да | — | Сегменты MP3 или AAC; MPEG-TS не разбирается |

## С чего начать

1. **Соберите плату** по [«Оборудованию»](doc/hardware.md) — или начните с
   минимума: модуль, дисплей, ЦАП и энкодер.
2. **Прошейте.** Быстрый путь — готовый образ из
   [релиза](https://github.com/jmper-ha/jradio/releases) одной командой
   `esptool.py`; полный — сборка из исходников под свою плату. Оба описаны в
   [«Сборке и прошивке»](doc/build.md), установка среды — в
   [«Установке среды разработки»](doc/toolchain.md).
3. **Подключите к Wi-Fi.** При первом включении устройство поднимает свою точку
   доступа `jradio-XXXX`: подключитесь к ней с телефона, откройте
   `http://192.168.4.1` и выберите домашнюю сеть. Дальше — [«Как
   пользоваться»](doc/usage.md).

## Что стоит знать заранее

- **Веб-интерфейс рассчитан на доверенную домашнюю сеть.** Пароля нет, наружу
  в интернет его открывать нельзя.
- **Не более 99 станций** в списке и **256 файлов** в одной папке носителя.
- **exFAT не поддерживается.** Флешки и карты от 64 ГБ обычно отформатированы
  именно в него — переформатируйте в FAT32.
- **Прошивается через UART**, а не через USB-разъём платы: USB отдан флешке.

Полный список ограничений — в [«Диагностике и ограничениях»](doc/diagnostics.md).
