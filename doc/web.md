# Веб-интерфейс

[← README](../README.md) · [English](web.en.md)

Открывается в браузере по адресу устройства (он показан внизу экрана
настроек) с телефона или компьютера в той же сети. Ничего устанавливать не
нужно. Русский и английский, тёмная и светлая тема.

**Аутентификации нет, `Origin` не проверяется. Интерфейс рассчитан на
доверенную домашнюю сеть — наружу не открывать.**

## Страницы

| Страница | Что на ней |
|---|---|
| **Плеер** (`/`) | Что играет, обложка, громкость, позиция, кнопки; выбор источника и списки станций, файлов и папок сервера; таймер сна и будильник |
| **Плейлист** (`/playlist`) | Редактор списка станций: имя, адрес, картинка, порядок перетаскиванием; проверка адреса «на слух» прямо на устройстве; импорт и экспорт |
| **Настройки** (`/settings`) | Всё, что есть на устройстве, плюс сети Wi-Fi, имя, время и пояс, погода, будильник, таймер сна, Яндекс Музыка, Bluetooth-колонки, резервная копия, «Об устройстве» |
| **Пульт** (`/remote`) | Обучение кнопок ИК-пульта; открывается кнопкой из настроек, если в сборке есть приёмник |

На телефоне разделы настроек складываются: открыт один, остальные — заголовками.
Живые данные (состояние плеера, списки, настройки) приходят по WebSocket, так
что открытая вкладка всегда показывает то же, что экран устройства, — в том
числе громкость, покрученную энкодером.

## Список станций

Строка — `имя<TAB>адрес<TAB>буква`, четвёртая колонка необязательна — имя
файла картинки. Буква говорит, какое имя показывать: `S` — то, которым
представляется поток, `L` — то, что записано в списке. Чужие плейлисты, где в
третьей колонке стоит коррекция громкости, читаются тоже: берутся имя и адрес.

Картинка станции выбирается в браузере, ужимается до 96 пикселей и хранится
на устройстве. Экспорт отдаёт `playlist.csv`, а если есть картинки —
`playlist.zip` с ними; импорт принимает и то, и другое. Порядок меняется
перетаскиванием за хваталку слева от названия (или стрелками с клавиатуры).
Всё уезжает на устройство по «Сохранить». До 99 станций.

## Пульт

Таблица функций с кнопками «Обучить» и «Забыть». Пока страница открыта,
нажатая кнопка пульта подсвечивает свою строку, а необученная называется
кодом — так узнают коды нового пульта. Обучение ждёт кнопку 30 секунд; если
её не дождались, страница так и пишет. Подробнее — [«Пульт»](usage.md#пульт).

## Резервная копия

`GET /api/backup` отдаёт zip с пятью файлами: `wifi.json` (сети),
`settings.csv` (настройки), `yandex.json` (токен), `weather.json` (ключ
OpenWeatherMap), `remote.csv` (обученные кнопки пульта). `POST /api/restore`
принимает архив целиком или один файл;
устройство проверяет все файлы до записи, пишет их и перезагружается. Список
станций в архив не входит — у него свой экспорт на странице плейлиста.

**В архиве пароль Wi-Fi, токен и ключ открытым текстом.** Устройство отдаёт его
любому в локальной сети. Храните файл как пароль.

## API

| Точка | Назначение |
|---|---|
| `GET /api/status` | Состояние Wi-Fi и плеера одним снимком |
| `GET /api/playlist` | Список станций в CSV |
| `POST /api/playlist` | Замена списка целиком |
| `GET /api/stations` | Имена станций активного источника; `?source=internet_radio` — всегда радио |
| `GET /api/files` | Содержимое текущей папки носителя |
| `GET /api/dlna` | Содержимое открытой папки медиасервера; `searching` — сервер ещё ищется |
| `GET /api/progress` | Позиция в треке, буфер, подпись обложки, остаток таймера сна |
| `GET /api/cover` | Текущая обложка, 96×96, BMP |
| `GET /api/settings` | Настройки устройства, список часовых поясов, сервер времени |
| `POST /api/settings` | Одна настройка: `{"field":…,"value":…}` — в том числе `timezone`, `ntp_server`, `weather*`, `screensaver*`, `alarm_*` |
| `POST /api/sleep-timer` | `{"minutes":45}`, ноль — выключить |
| `GET /api/about` | Версии прошивки, веб-интерфейса и ESP-IDF |
| `GET /api/backup`, `POST /api/restore` | Резервная копия, см. выше |
| `POST /api/station-test` | Проиграть адрес на устройстве, не трогая плейлист |
| `POST /api/station-icon`, `GET /api/station-icon` | Загрузить / получить картинку станции |
| `GET /api/yandex`, `POST /api/yandex` | Состояние привязки и станции аккаунта; привязать, отвязать, обновить |
| `GET /api/remote`, `GET /api/remote/last` | Таблица пульта; последняя принятая кнопка |
| `POST /api/remote/learn`, `POST /api/remote/forget` | `{"function":"volume_up"}` — обучить / забыть |
| `POST /api/wifi` | Сохранить сеть |
| `POST /api/wifi-scan`, `GET /api/wifi-scan` | Поиск сетей (только без подключения) и его результат |
| `/ws` | Команды и живые обновления |

**Команды WebSocket:** `player.play`, `player.pause`, `player.toggle`,
`player.next`, `player.previous_item`, `player.next_item`, `player.seek`
(секунда), `player.like`, `player.dislike`, `source.select`, `list.select`,
`browse.up`, `wifi.save`, `wifi.forget`, `wifi.prioritize`, `wifi.disconnect`.
Обратно идут диффы секций `player`, `list`, `wifi`, `settings`. Крупное —
плейлист, папки, позиция, обложка — идёт через REST, чтобы не грузить сокет.

Коды пульта записываются как `nec:<адрес>:<команда>` (`nec:4:08`) либо
`raw:<хеш>` для протокола, который декодер не знает.

Будильник в настройках — пять полей: `alarm_enabled`, `alarm_time` (`"07:30"`),
`alarm_days` (маска, бит 0 — воскресенье, ноль запрещён), `alarm_station`
(номер с единицы), `alarm_volume`.

## Как это устроено

Статика лежит в разделе данных и отдаётся сжатой, с `ETag`: после обновления
раздела браузеру хватает обычной перезагрузки страницы. Настройки, изменённые
из браузера, применяются на устройстве сразу; изменённые на устройстве —
доезжают до страницы за четверть секунды. Язык хранит устройство, поэтому
переключатель на странице и строка на экране — это один переключатель.
