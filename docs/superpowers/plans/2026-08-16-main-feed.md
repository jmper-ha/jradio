# Главный экран «Лента» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Добавить в главный экран jradio горизонтальную карусель функций с bitmap-иконками, управляемую энкодером, сохранив существующий режим «Список».

**Architecture:** Чистая тестируемая модель `ui_feed_model` хранит выбранный пункт и циклическую навигацию. LVGL-слой создаёт отдельный feed screen, отображает пять позиций карусели и переиспользует существующие маршруты источников/настроек. Нереализованные пункты остаются визуальными заглушками и не запускают аудио.

**Tech Stack:** C17, ESP-IDF 5.5.4, FreeRTOS, LVGL 9, существующий `ui_menu`, `device_settings`, board input и host test runner.

## Global Constraints

- Разрешение дисплея: 320×240 landscape.
- Иконки — встроенные монохромные bitmap-ресурсы без Unicode-emoji и внешних файлов.
- Порядок пунктов: Интернет-радио, USB, Bluetooth, FM-радио, DLNA, Яндекс Музыка, Настройки.
- «Список» не меняет существующее поведение.
- Bluetooth, FM, DLNA и Яндекс остаются заглушками.
- Все изменения должны пройти `./tests/run_host_tests.sh` и `idf.py build`.
