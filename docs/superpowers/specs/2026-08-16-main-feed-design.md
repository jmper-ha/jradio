# Дизайн главного экрана «Лента»

## Цель

Добавить альтернативный главный экран устройства — горизонтальную ленту функций. Режим выбирается настройкой «Общие → Главный экран»: «Список» сохраняет существующее поведение, «Лента» открывает новый экран.

## Компоновка

- Экран: 320×240, текущая ориентация и текущая LVGL-тема.
- В верхней части по центру отображается название выбранной функции.
- В средней части размещается горизонтальная циклическая карусель иконок.
- Выбранная иконка всегда находится в центре, имеет больший размер и контрастную рамку/подсветку.
- Соседние иконки видны слева и справа, уменьшены и приглушены.
- Иконки монохромные, кодовые bitmap-ресурсы без зависимости от Unicode-шрифтов.
- Для функций без реализации отображаются серые иконки-заглушки; их название всё равно показывается.

## Элементы ленты

Порядок соответствует основному меню:

1. Интернет-радио — антенна/радиоволны.
2. USB — символ USB-разъёма.
3. Bluetooth — логотип Bluetooth.
4. FM-радио — радиоприёмник.
5. DLNA — узлы сети.
6. Яндекс Музыка — нота.
7. Настройки — шестерёнка.

Реализованные источники используют существующие переходы приложения. Нереализованные источники (Bluetooth, FM, DLNA, Яндекс) остаются заглушками и не запускают аудиопоток.

## Управление

- Поворот энкодера влево/вправо циклически перемещает выбранную иконку на один пункт.
- Короткое нажатие энкодера активирует выбранный пункт.
- Для поддержанного пункта открывается существующий экран/режим.
- Для заглушки остаёмся на ленте и показываем существующее уведомление «Функция пока недоступна».
- При повторном входе на главный экран выбранный пункт сохраняется в памяти UI до перезапуска; отдельная настройка для позиции не добавляется.
- Режим «Список» не изменяется.

## Архитектура

- Добавляется чистая модель карусели с индексом выбранного элемента, циклической навигацией и признаком доступности.
- UI-слой отвечает только за создание экрана, размещение bitmap-иконок и обновление пяти видимых позиций (центр, два соседа с каждой стороны).
- Идентификаторы пунктов переиспользуют существующие `ui_menu`/`audio_source` значения, чтобы не дублировать маршрутизацию.
- Переключение режима главного экрана использует уже существующие настройки и применяется при следующем открытии главного экрана.

## Проверка

- Host-тесты модели: циклический переход в обе стороны, фиксация центрального элемента, активация поддержанных и заглушек.
- Проверка сборки ESP-IDF.
- Ручная проверка на дисплее: центрирование, контраст выбранной иконки, работа энкодера, вход в интернет-радио/настройки и уведомление для заглушки.
