# Экран настроек с раскрывающимися группами

## Цель

Добавить на LVGL-экране настроек вертикальный список групп с раскрытием,
изменением параметров энкодером и немедленным применением/сохранением каждого
изменения в `settings.csv`.

## Пользовательское поведение

В свернутом состоянии экран показывает заголовки групп одну под другой:

```text
> Язык
  Общие
  Экран
```

Нажатие энкодера на заголовке раскрывает группу. Поля появляются сразу под
заголовком на более светлом фоне:

```text
v Язык
    Язык: Русский
  Общие
  Экран
```

В раскрытой группе курсор перемещается только по её заголовку и полям. Повторное
нажатие на заголовке закрывает группу и возвращает навигацию к списку групп.
Переход между группами закрывает ранее раскрытую группу.

Настройки применяются немедленно и сохраняются в `settings.csv` сразу после
успешно принятого изменения. Ошибка записи не должна менять отображаемое
значение без уведомления пользователю или отката к последнему сохранённому
значению.

## Группы и параметры

### Язык

Выпадающий список:

- `Русский`;
- `English`.

После смены языка текущий экран и последующие экраны перерисовываются с новым
набором подписей.

### Общие

Параметр `Главный экран` — выпадающий список:

- `Текст`;
- `Лента`.

Новое значение используется при следующем открытии главного экрана и не требует
перезапуска устройства.

### Экран

Два независимых графических переключателя:

- `Поворот по вертикали`;
- `Поворот по горизонтали`.

Каждый переключатель сразу обновляет ориентацию ILI9341. Комбинация двух
переключателей соответствует повороту на 180 градусов; отдельный переключатель
меняет соответствующую ось.

## Архитектура

Экран настроек использует существующую LVGL UI-задачу и существующий слой
настроек. Модель групп и навигации должна быть отделена от отрисовки, чтобы её
можно было проверить host-тестами без ESP-IDF. UI вызывает типизированную
операцию изменения параметра; слой настроек валидирует значение, обновляет
модель, сериализует строку `settings.csv` и возвращает результат UI.

Формат файла остаётся построчным CSV `ключ,значение`. Существующие ключи должны
сохраняться при добавлении новых, неизвестные ключи должны переживать чтение и
повторную запись. Для новых параметров используются стабильные ключи:

- `language=ru` или `language=en`;
- `home_screen=text` или `home_screen=feed`;
- `display_flip_vertical=0|1`;
- `display_flip_horizontal=0|1`.

## Ошибки и ограничения

- Неверное значение в `settings.csv` заменяется безопасным значением по
  умолчанию.
- Если запись LittleFS не удалась, значение в UI возвращается к предыдущему
  сохранённому значению и выводится диагностическое сообщение.
- В группе может быть раскрыта только одна группа одновременно.
- Длинные подписи должны обрезаться или переноситься без выхода за границы
  экрана 320×240.

## Проверка

Добавляются host-тесты для:

1. порядка групп и переходов курсора в свернутом/раскрытом состояниях;
2. запрета выхода курсора за пределы раскрытой группы;
3. корректного открытия/закрытия группы по нажатию заголовка;
4. выбора значений выпадающих списков и переключателей;
5. чтения, записи и сохранения неизвестных строк `settings.csv`;
6. немедленной генерации операций применения настроек.

После тестов выполняется полная сборка ESP-IDF для ESP32-S3.
